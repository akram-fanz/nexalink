# PHASE 4: Messaging Foundation — Plan

## Goal
Implement text messaging foundation: message types, normalized model, send/receive text, event handling, validation.

## Current State
- PHASE 3 complete: connection manager + session store + stub auth
- `client.connect()` reaches `authenticating` but no real protocol
- Transport layer ready, events wired

## Architecture

```
NexaClient
    └── MessageService
        ├── MessageSerializer (text → binary stub)
        ├── MessageParser (binary → NexaMessage)
        └── MessageValidator (Zod schemas)
```

## Tasks

### 1. Message Types & Model (30 min)
**File:** `src/messaging/types.ts`
- Define `NexaMessage` interface (id, from, to, timestamp, type, text, quoted, mentions)
- Define `MessageType` enum
- Define `SendMessageOptions` for public API

**File:** `src/messaging/model.ts`
- `normalizeMessage()` — validate + fill defaults
- `generateMessageId()` — timestamp-based ID

### 2. Message Validator (20 min)
**File:** `src/messaging/validator.ts`
- Zod schemas for text message fields
- `validateSendOptions()` — throws `ValidationError`

### 3. Message Service (60 min)
**File:** `src/messaging/service.ts`
- `class MessageService`
- `async sendText(to, text, options?)` — serialize, send via transport
- `handleIncomingMessage(binary)` — parse, validate, emit event
- Wire to `ConnectionManager` message handler

### 4. Wire to Client (30 min)
**File:** `src/client/phase3.ts`
- Instantiate `MessageService` in `NexaClientPhase3`
- Add `sendMessage(to, options)` to `NexaClient` interface
- Connect message handler

### 5. Tests (40 min)
- `tests/unit/message-model.test.ts` — normalize, validate
- `tests/unit/message-service.test.ts` — send/receive with mock transport
- Update client test to verify `sendMessage` exists

### 6. Docs (20 min)
- Update README with sendMessage example
- CHANGELOG 0.3.0
